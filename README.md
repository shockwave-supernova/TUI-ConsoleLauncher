# T-UI Next (`com.tui.next`) — Linux CLI Launcher для Android 17

**T-UI Next** — модернизированный терминальный лаунчер для Android с полноценным интерфейсом командной строки (CLI), адаптированный под **Android 17 (API 37)** без использования Root-доступа или Shizuku.

---

## Основные возможности и изменения в `com.tui.next`

- **Полная поддержка Android 17 (`compileSdk = 37`, `targetSdk = 37`, `minSdk = 26`)**:
  - Корректная обработка системных отступов (`Edge-to-Edge` / `WindowInsetsCompat`) с учетом статус-бара, жестовой навигации, вырезов экрана (`DisplayCutout`) и экранной клавиатуры (`IME`).
  - Современная модель разрешений Android 13–17 без Root и Shizuku: `MANAGE_EXTERNAL_STORAGE`, `READ_MEDIA_AUDIO`, `POST_NOTIFICATIONS`, `BLUETOOTH_CONNECT`, `BLUETOOTH_SCAN`, `QUERY_ALL_PACKAGES`, `SEND_SMS`, `READ_CONTACTS`.
- **Интеграция с Google Gemini (`gemini`)**:
  - Быстрый ярлык `gemini` в нижней панели подсказок и одноименная команда запускают ИИ-ассистента Google Gemini в одно касание.
- **Увеличенная панель управления**:
  - Кнопки навигации под строкой ввода (очистка, история вверх/вниз, вставка из буфера обмена и клавиша `Enter`) адаптированы под экраны высокого разрешения.
- **Мгновенная прозрачность и системные обои**:
  - Автоматическая перезагрузка окна (`recreate()`) сразу после выдачи разрешения на доступ к хранилищу при первом запуске — системные обои применяются мгновенно без ручного перезапуска.
- **Динамический статус-бар**:
  - Автоматическое определение имени пользователя (`user.name` / `Build.USER`) и реальной модели устройства (`Build.MODEL`).
- **Актуализированные системные модули**:
  - **Музыка (`music`)**: поддержка `READ_MEDIA_AUDIO`, локальной медиатеки (`MediaStore` / папки `Music`) и управления внешними медиаплеерами через `AudioManager.dispatchMediaKeyEvent`.
  - **Вибрация (`vibrate`)**: поддержка `VibratorManager` и `VibrationEffect` с атрибутами `AudioAttributes.USAGE_ALARM`.
  - **RSS (`rss`)**: мультиформатный парсер дат публикации (`pubDate`) с поддержкой стандартов RFC-822, RFC-1123 и ISO-8601.
  - **Файлы (`share`, `open`)**: безопасная передача URI через `FileProvider`.
  - **Счетчик разблокировок (`Unlock counter`)**: корректный прием `Intent.ACTION_USER_PRESENT` с флагом `RECEIVER_EXPORTED` на Android 14–17.

## Установка

### Установка готового APK
1. Скопируйте APK-файл `app-fdroid-debug.apk` на устройство или установите через ADB:
   ```bash
   adb install -r app/build/outputs/apk/fdroid/debug/app-fdroid-debug.apk
   ```
2. При первом запуске выдайте разрешение **«Доступ ко всем файлам» (`All files access`)** для работы с конфигурационной папкой `/sdcard/t-ui` и подтвердите стандартные системные запросы разрешений.
3. При необходимости выберите **T-UI** в качестве домашнего экрана по умолчанию в настройках Android.

### Сборка из исходного кода
Требования:
- **Android SDK**: `platforms;android-37.0`, `build-tools;37.0.0`
- **Gradle**: `9.6.1` (автоматически подтягивает JDK 21 через Gradle Java Toolchains)

Команда сборки:
```bash
chmod +x gradlew
./gradlew assembleFdroidDebug
```
Готовый APK будет создан по пути:
`app/build/outputs/apk/fdroid/debug/app-fdroid-debug.apk`

## Справочник ключевых команд

| Команда | Описание |
| :--- | :--- |
| `<имя приложения>` | Запуск любого установленного приложения по имени |
| `gemini` | Быстрый запуск приложения или голосового ассистента Google Gemini |
| `apps -ls` / `-lsh` / `-hide` / `-show` | Управление списком приложений, скрытыми приложениями и группами |
| `theme -preset [name]` | Быстрое переключение цветовых пресетов (`blue`, `red`, `green`, `pink`, `bw`, `cyberpunk`) |
| `config -set [option] [value]` | Изменение настроек (`behavior.xml`, `ui.xml`, `theme.xml`, `suggestions.xml`, `toolbar.xml`) |
| `config -file [file]` | Открытие конфигурационного XML-файла во встроенном редакторе `tuixt` |
| `username [user] [device]` | Изменение имени пользователя и названия устройства в статус-баре |
| `music -play` / `-next` / `-previous` / `-stop` / `-ls` | Управление встроенным аудиоплеером или активной медиа-сессией |
| `vibrate [мс \| паттерн]` | Вибрация заданной длительности (`vibrate 300` или `vibrate 0,200,100,200`) |
| `rss -add [id] [sec] [url]` / `rss -l [id]` | Добавление и чтение RSS/Atom-лент |
| `notes -add [текст]` / `-ls` / `-rm` | Управление заметками на главном экране |
| `call [контакт \| номер]` | Быстрый телефонный вызов |
| `sms [контакт \| номер]` | Отправка SMS-сообщения прямо из консоли |
| `wifi` | Открытие системной панели быстрого переключения Wi-Fi и интернета |
| `data` | Переход к настройкам мобильной передачи данных |
| `bluetooth` | Включение/выключение Bluetooth |
| `flash` | Включение/выключение фонарика (`CameraManager.setTorchMode`) |
| `open [путь]` | Открытие файла во внешнем приложении через `FileProvider` |
| `share [путь]` | Отправка файла через системное меню «Поделиться» |
| `tuixt [файл]` | Встроенный консольный текстовый редактор |
| `search -gg` / `-yt` / `-dd` / `-u` | Поиск в Google, YouTube, DuckDuckGo или открытие URL |
| `calc [выражение]` | Встроенный калькулятор (`+`, `-`, `*`, `/`, `%`, `^`, `sqrt`) |
| `status` | Вывод сводки о батарее, Wi-Fi, мобильной сети и Bluetooth |
| `clear` | Очистка экрана терминала |
| `restart` | Перезапуск лаунчера с применением новых настроек |
| `help [команда]` | Справка по всем командам или конкретной команде |

## Хранение конфигурации

Все конфигурационные файлы хранятся в папке `/storage/emulated/0/t-ui/`:
- `behavior.xml` — поведение терминала, форматы времени, разблокировок и команд
- `ui.xml` — параметры интерфейса, отступы, размеры шрифтов, статус-бар
- `theme.xml` — цвета текста, фона, рамок и элементов управления
- `suggestions.xml` — настройки нижней панели быстрых подсказок
- `alias.xml` — пользовательские алиасы команд
- `apps.xml` — группы приложений и статистика запусков
- `rss.xml` — подписки и правила фильтрации RSS
- `notifications.xml` — фильтрация и цветовая разметка уведомлений
